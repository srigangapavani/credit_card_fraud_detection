Credit Card Fraud Detection

Developed a machine learning-based system to identify fraudulent credit card transactions.
Performed data cleaning, exploratory data analysis (EDA), and data visualization on 284,807 transactions.
Handled highly imbalanced transaction data using class-weight techniques.
Applied feature scaling using StandardScaler and performed an 80:20 train-test split.
Implemented and evaluated Random Forest, XGBoost, LightGBM, and CatBoost classification algorithms.
Evaluated model performance using Accuracy, Precision, Recall, F1-score, Confusion Matrix, and ROC-AUC.
Achieved 99.96% accuracy on training data and 99.96% accuracy on test data with Random Forest, with 80% fraud-class recall and 0.9813 ROC-AUC.

Technologies: Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, XGBoost, LightGBM, CatBoost
